# AERIS POOL

Images, pool plans, fonts and interactive assets for the [published AERIS POOL site on Aura](https://aeris-pool-website-29.aura.build/).

[`site/index.html`](site/index.html) is the current single-file landing page imported into Aura. Its page-specific styles and scripts are inlined; the shared media and libraries are loaded from this repository through jsDelivr.

The quote form needs a submission service before it can receive enquiries on Aura or GitHub Pages. No customer data or credentials are stored in this repository.
